Closing one issue

For a single issue the agent writes a resolution message in the chat instead of a file. It serves as the commit message, and closes the issue on the web: open the card's Edit triage, set the status to Resolved, select where the fix went under Resolved via, paste the message into Resolution, give Fixed in version for an Overseer release, and save.
