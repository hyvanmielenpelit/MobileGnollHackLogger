Database Maintenance Tasks

Run Scheduled Maintenance Pass

Runs the full nightly pipeline, in order:

  1. Expires sessions inactive over {{ inactivityDays }}d, and sessions past their own TTL (confidential sessions set to purge are removed outright)
  2. Finds trash older than the {{ storageMetrics.policy.softDeleteGracePeriodDays }}d grace period
  3. Permanently purges it, with its disk folders
  4. Prunes chat tool payloads over {{ toolCallPruneDays }}d
  5. Prunes benchmark tool payloads for runs over {{ storageMetrics.policy.pruneBenchmarkToolCallResultsDays }}d
  6. Sweeps orphaned disk folders
  7. Deletes access journal rows over {{ daysLabel(storageMetrics.policy.auditLogRetentionDays) }}
  8. Deletes dismissed AI errors over {{ daysLabel(storageMetrics.policy.pruneDismissedAiErrorLogDays) }} since dismissal
  9. Deletes maintenance history over {{ daysLabel(storageMetrics.policy.maintenanceHistoryRetentionDays) }}
Empty All Trash Now

Bypasses the {{ storageMetrics.policy.softDeleteGracePeriodDays }}-day grace period and immediately purges all soft-deleted sessions and their disk attachments across all users.

Purge Inactive Sessions

Soft-deletes active, unpinned sessions with no activity past the threshold. Also expires sessions past their own TTL whatever the threshold, and permanently purges confidential sessions set to purge on delete.

Prune Aged Tool Results

Truncates raw tool call JSON payloads without deleting user message transcripts.

Prune Benchmark Tool Payloads

Nulls the arguments and results of benchmark tool calls for runs older than the threshold. Names, statuses and timings are kept.

Prune Access Journal

Deletes ChatAccessAuditLog rows older than the configured {{ daysLabel(storageMetrics.policy.auditLogRetentionDays) }}. The only action that removes audit rows.

Prune Dismissed AI Errors

Deletes AI error rows dismissed more than the threshold ago. Undismissed errors are never pruned.

Sweep Orphaned Disk Folders

Scans ConversationsDataLocation for disk folders whose session ID no longer exists in the database.

Clear Report Chart Files

Deletes every chart image in the report chart folder. The report documents and their text are kept; their PDF and Word copies have no charts until Update charts in the Comparison Wizard adds them again.
