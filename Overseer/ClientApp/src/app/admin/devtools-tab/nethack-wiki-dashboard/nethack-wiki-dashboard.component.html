How to regenerate

The wiki folder is converted from a NetHack wiki dump outside Overseer. This dashboard never runs the converter.

Steps to regenerate the wiki
  1. Back up the current wiki folder to a new dated folder under C:\Backup\NetHack Wiki.
  2. Run the converter as Overseer/Scripts/NetHackWiki/README.md describes.
  3. Remove the old generated files from the wiki folder @if (status?.path; as path) { ({{ path }}) } so that only the new conversion remains.
  4. Click Re-index wiki on this page.
