Batteries

A battery is a fixed set of two or more suites with declared weights. A battery run tests one model on every suite, one after another, and combines the results into an Overall Intelligence Index with an uncertainty interval. Start one from Run Benchmark with Run Target set to Battery; battery runs are listed in Run History, and each battery's Leaderboard ranks the results of its current definition.
