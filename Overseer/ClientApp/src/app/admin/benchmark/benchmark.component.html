Identity
Shown in the scoring profile selector on the benchmark setup form. Names must be unique.
Dimension weights
The evaluator rates each answer 0–6 on four dimensions. Each level is converted to points through the level score table below, then combined into one quality score as a weighted geometric mean: Quality = AccwAcc × CompwComp × ConcwConc × ReadwRead, clamped to 1–100. Because the mean is geometric, a near-zero score on any one dimension drags the whole result down — a weight cannot fully compensate for a collapsed dimension. The four weights must sum to exactly 1.0; the profile is rejected on save otherwise.
Factual correctness against GnollHack game and source-code facts. Default 0.55.
Coverage of the question — conditions, exceptions, and edge cases, not just the headline answer. Default 0.25.
Information density: how little padding, repetition, and filler surrounds the answer. Default 0.10.
Structure, formatting, and how easily the answer can be scanned. Default 0.10.
Rating scale
Maps each Behaviorally Anchored Rating Scale level (0–6) onto a point value used by the quality formula. Exactly 7 integers, strictly ascending, each between 1 and 100. The default [1, 15, 35, 55, 72, 87, 100] is spaced unevenly on purpose: the gaps are widest through the middle of the scale (20 points per level) and narrowest at the top (13 points), so competent answers separate more sharply than near-perfect ones. Widen the upper gaps to make top-end differences more decisive.
Speed
The base response time that scores a full 100 speed points. Speed is 100 - k × log2(modelTime / effectiveTarget), clamped to 1–100, where modelTime is the turn duration with tool I/O removed. Must be greater than 0. Default 15000.
Speed points lost per doubling of model time past the effective target. At the default 20, a response taking 4× the target scores 60 and one taking 8× scores 40. Higher values punish slow answers harder; lower values flatten the curve. Must be greater than 0.
How much an answer's assessed difficulty raises its expected time: effectiveTarget = target × (1 + scaling × difficulty / 100). At the default 1.0 a difficulty-100 question is allowed twice the base target, while 0 holds every question to the same target. Difficulty enters the Speed Index here and nowhere else — the index itself is an equal-weight mean, so a hard question is given more time rather than more weight. Must be between 0.0 and 5.0.
Execution
How many of the suite's questions are sent to the target model simultaneously. 1 gives strict sequential timing. Above 1 the run finishes sooner in wall-clock time, but each recorded duration includes queueing against the concurrent requests — the run is flagged as concurrency-degraded and its Speed Index becomes advisory only. Minimum 1.
The highest quality score an answer may keep when the evaluator flags a critical error — a confidently asserted falsehood a player would act on to their direct detriment. Applied as a cap after the weighted score is computed: a flagged answer scoring above this value is reduced to it; one already below is left unchanged. Must be between 1 and 100. Default 25.
Quality score below which an answer is re-graded by the run's second opinion assessor, if one was selected when the run was started. An answer flagged with a critical error is re-graded whatever its score. Both verdicts are kept and a material disagreement is flagged for review; the first verdict is what scores. 0 disables the score trigger and leaves second opinions to critical errors alone. Must be between 0 and 100. Default 50.
The default for runs started with this profile; the start dialog can override it for a single run. Every answer (double grading) is recommended: under the trigger-based modes the disagreement rate is conditioned on the first assessor's own uncertainty, so it measures nothing about the instrument. Inert on a run started without a second opinion assessor.
Quality points below the run's own median at which an answer is re-graded, under Flagged answers and statistical outliers only. An absolute threshold cannot see an outlier in an otherwise strong run; this can. Must be between 1 and 100. Default 25.
Availability
The default profile is preselected on the benchmark setup form. Exactly one profile is the default at any time — turning this on clears the flag from the profile that currently holds it. The last remaining default cannot be un-set.
