About Experimental Changes

A variant is a named, test-only bundle of changes to the AI's tools and instructions: an experimental tool, a tool-output switch, a reworded tool description, or extra instructions at the end of the AI's instructions. It exists so that a proposed chat change can be measured before it reaches users. Its files are hashed into the run, so a run always says exactly what it used.

  • Compare in pairs. A run with a variant is compared with a run that is identical except for Experimental Changes, on the Paired Test tab of its report. Leave one feature out is compared with a run of the whole variant; Only one feature with a run without Experimental Changes.
  • Source code only first, then Production. The wiki cannot mask the effect under Source code only; the Production pair shows the change does not hurt where the wiki helps.
  • Declare the criteria before the runs, cost among them: input tokens and model time. A change that adds tool rounds can win on quality and lose on cost.
  • One ablation at a time, and confirm a winner on a second suite. Running every ablation on one suite of about 11 questions and keeping the best is a multiple-comparisons trap: one of them will look better by chance.
  • Never compare a variant run with production runs in Model Comparison. Its scores measure a different set of instructions.
