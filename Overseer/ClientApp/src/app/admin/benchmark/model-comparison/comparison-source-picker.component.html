What to compare

A single run contributes one point at R = 1; an analysis group contributes one point pooled over its members. Compare is explicit rather than live: every request re-prices each entry server-side, so a refetch per checkbox would be a request per click.

Scopes which runs and groups are offered below.

What "condition" means

A comparison can only chart sources that agree on every must-match key — that cohort is a condition. Only the largest condition on offer can be charted; every source outside it is excluded from the comparison rather than plotted beside it.
