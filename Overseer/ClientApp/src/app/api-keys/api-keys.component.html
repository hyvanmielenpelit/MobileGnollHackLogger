About the advanced settings

Parallel execution

How much Overseer may ask this key to do at once.

Overseer can run several tool calls and subagents at the same time on one key. Keep this on Allowed unless the provider rate-limits you, which mostly happens on free or low-tier plans.

AllowedDefault
Fastest, and the right choice for almost everyone.
On request
Asks the model to hold back. It is a request, not a limit.
Sequential only
One call at a time. The fix for a key that keeps hitting rate limits: chats get slower, but they stop failing.

Confidential chats

These settings apply only in chats you mark confidential. Nothing here affects a normal chat.

They decide two things: whether Overseer will use this key in a confidential chat at all, and what colour the Private badge shows there.

Overseer cannot check what you agreed. Only you can see your agreement with the provider, so whatever you record here is self-declared. It shows as unverified, and the badge is yellow at best — never green. Green needs a model an administrator has verified.
