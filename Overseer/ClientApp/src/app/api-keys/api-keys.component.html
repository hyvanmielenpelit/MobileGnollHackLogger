How to get an API Key

To use OpenAI models, you need an API key from your OpenAI account.

  1. Go to platform.openai.com/api-keys
  2. Log in or sign up.
  3. Click Create new secret key.
  4. Copy the key and paste it here.

To use Anthropic models, you need an API key from the Anthropic Console.

  1. Go to console.anthropic.com/settings/keys
  2. Log in or sign up.
  3. Click Create Key.
  4. Copy the key and paste it here.

To use Google Gemini models, you need an API key from Google AI Studio.

  1. Go to aistudio.google.com/app/apikey
  2. Log in with your Google account.
  3. Click Create API key.
  4. Copy the key and paste it here.
