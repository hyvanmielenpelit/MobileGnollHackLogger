} @case ('masking') {

Masking is not part of Confidentiality Mode and is not chosen per chat. A class switched on here is masked in every outbound turn, in every chat, confidential or not, from now on.

A safety net, not a guarantee

Masking reduces accidental credential leakage, it does not guarantee it. Only values with a recognisable shape are caught.

A secret with no recognisable shape passes straight through, unmasked: a password typed on its own, an internal hostname, an ID number from outside the US, or a token in a format Overseer does not know.

How it works

  1. Overseer recognises a value of a class you have switched on.
  2. It replaces the value with a placeholder before the prompt leaves the server.
  3. It puts your own value back in the reply. You keep seeing your value; the provider only ever receives the placeholder.
Credentials and payment data

On by default.
